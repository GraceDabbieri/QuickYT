# QuickYT

QuickYT is a simple Python script for reading YouTube live chat directly from the command line. It is designed to be fast, lightweight, and accessible, making it easier to follow live chats without needing a full browser.

Run the script, press enter, paste the video URL, and the chat appears in your terminal.

This project focuses on accessibility. Messages can also be spoken aloud, making it easier to follow along in a way that works best for you.

## How it works

- Prompts you to enter a YouTube video URL  
- Asks if you would like speech output  
- Connects to the live chat for that stream  
- Displays messages in real time in your terminal  
- Speaks messages aloud for improved accessibility  

## Setup

Before running QuickYT, you will need Python 3 installed on your system.

- Download Python 3 from: https://www.python.org/downloads/  
- Make sure `python3` and `pip` are available in your terminal  

Install pytchat thru pip, it is a required dependencie:

pip install pytchat
